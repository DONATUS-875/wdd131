Nigeria Tourist Attractions - Website Planning Document

WDD 131 Final Project Site Plan

Site Name

Nigeria Tourist Attractions

This name clearly describes the purpose of the website. It informs visitors that the website provides information about Nigeria's most popular tourist attractions and encourages tourism throughout the country.

Site Purpose

The purpose of this website is to provide useful information about Nigeria's famous tourist attractions. Visitors will lear about each destination through descriptions, locations, photographs, travel information, and interesting facts. The website will also include responsive web design and interactive JavaScript features to provide an engaging user experience on mobile and desktop devices.

Scenarios

  • Which tourist attractions are the most popular in Nigeria?
  • Where is Zuma Rock located and how can I visit it?
  • What activities are available at Yankari National Park?
  • Which tourist attraction is best for a family vacation?
